# 로또 미션 - 구현 계획

## 리팩토링 목표

- 리팩토링 시 `Stream API` 적용 고려

---

## 구현할 기능 목록

1. **로또 게임 시작 진입점 설정**
2. **로또 게임 입력 기능 구현**
    - 2-1. 구입 금액 입력
    - 2-2. 구입 금액 검증, 예외 발생 시 `IllegalArgumentException`
3. **로또 만들기**
    - 3-1. 로또 검증
    - 3-2. 구입 금액으로 살 수 있는 로또 개수 구현
    - 3-3. 로또 만들기 구현
    - 3-4. 만든 로또 출력하기
4. **당첨 번호, 보너스 번호 입력 받기**
    - 4-1. 당첨 번호, 보너스 번호 입력 받기
    - 4-2. 당첨 번호, 보너스 번호 검증
5. **당첨 통계 내기**
    - 5-1. 등수별 보상 정보 객체 구현
    - 5-2. 로또 번호와 당첨 번호, 보너스 번호 일치 여부 확인
    - 5-3. 총 얻은 금액 계산하기
    - 5-4. 총 수익률 계산하기
6. **결과 출력하기**
    - 6-1. 통계 출력하기
    - 6-2. 수익률 출력하기

## 대략적인 설계

### `Application`

- 진입점

### `InputView`

- 입력할 때 안내사항 출력, 입력받기
    - 구입금액 입력
    - 구입 금액 검증
    - 당첨 번호 입력
    - 보너스 번호 입력

### `Lotto`

- 로또 한 장의 객체, 자체 검증 및 로직 담당
    - 로또 검증: 번호 범위
    - 로또 검증: 숫자 6개
    - 로또 검증: 중복되지 않는 숫자
    - 생성자에서 검증하고 생성
    - 로또 번호 getter

### `LottoController`

- 로또 로직과 view, service 연결

### `LottoService`

- 로또 만들기, 일치 여부, 계산 등 비즈니스 로직 담당

### `WinningNumbers`

- 당첨 번호 객체, 자체 검증 및 로직 담당
    - 당첨 번호 검증: 숫자 범위
    - 당첨 번호 검증: 숫자 6개
    - 당첨 번호 검증: 중복되지 않는 숫자
    - 당첨 번호는 `Lotto` 이용
    - 보너스 번호 검증: 숫자 범위
    - 보너스 번호 검증: 숫자 1개
    - 보너스 번호 검증: 당첨 번호와 중복X
    - 생성자에서 검증하고 생성
    - 당첨 번호, 보너스 번호 관리
    - 당첨 번호 일치 여부 확인

### `PurchaseAmount`

- 구입 금액 담당
  - 구입 금액 검증: 숫자인지
  - 구입 금액 검증: 1000으로 나눠지는지
  - 로또 몇 장인지 계산하는 기능

### `BonusNumber`

- 보너스 숫자 담당
  - 보너스 숫자 검증: 숫자인지
  - 보너스 숫자 검증: 1~45 사이인지
  - 보너스 숫자 검증: 당첨 번호와 중복되는 번호인지

### `PrizeStatistics`
- 총 얻은 금액 계산
- 수익률(총 얻은 금액 / 구입 금액 * 100) 계산

### `Prize`

- 등수별 일치하는 숫자 개수, 보너스 숫자 포함 유무 및 보상 정보 `enum`

### `OutputView`

- 결과물 출력
    - 구매 내역 출력
    - 당첨 통계 출력
    - 수익률 출력
